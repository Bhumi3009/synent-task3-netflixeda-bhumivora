# Synent Technologies Internship - Task 3
# Netflix Dataset Exploratory Data Analysis

## Problem Statement

Analyze Netflix content to identify trends, patterns, and insights through exploratory data analysis and visualization.

## Dataset Details

Dataset Name: Netflix Movies and TV Shows

Source: Kaggle

Features:
- Title
- Type
- Country
- Rating
- Release Year
- Date Added
- Genre

## Approach

1. Loaded and explored dataset.
2. Checked missing values.
3. Generated summary statistics.
4. Performed trend analysis.
5. Created visualizations:
   - Movies vs TV Shows
   - Content Added Over Time
   - Top Countries
   - Rating Distribution
   - Genre Analysis
6. Performed correlation analysis.

## Results

- Movies dominate Netflix content.
- Significant growth in content occurred after 2015.
- United States contributes the highest amount of content.
- TV-MA is among the most common ratings.
- Drama and International content are highly represented.
